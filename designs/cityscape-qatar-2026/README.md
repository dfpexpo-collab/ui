# Cityscape Qatar & VOOM: story 1080×1920

- `story.svg`: editable master. All copy is live text (Gabarito), and the VOOM End-to-End logo is a vector symbol. Layers are named groups: `background`, `headline`, `ampersand`, `voom-logo-end-to-end`, `info-card` (`booth`, `date`), `ribbons`.
- `story.png`: preview render.
- `build.py`: generator. Change the copy at the top and run `python3 designs/cityscape-qatar-2026/build.py`.

Open in Illustrator or Figma (File → Import / drag the SVG in). Install Gabarito first (`.claude/skills/voom-brand/assets/fonts/`, or Google Fonts) so the text stays live and correct.
