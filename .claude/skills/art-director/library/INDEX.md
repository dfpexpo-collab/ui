# Creative library index

Map of every specialist skill the art director routes to, by craft. Links to `../../<name>/SKILL.md` are the live skills installed in this repo (the only copy; edits to them show up here at once). Folders inside `library/` hold the skills that are not installed in the repo (content/marketing, design research, Adobe production, generative/static design) and the external packs (designer-skills: 111 skills, art-direction); their entry file is `GUIDE.md` so they do not register twice.

The Voom brand system stays in its own skill: `../../voom-brand/` (single source of truth). Skills added after this index was written are listed in `/Mado.md`.

Read the linked file for the craft, then judge with the gate in ../SKILL.md.
